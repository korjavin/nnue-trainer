# NNUE v3.1 — ridge-distill the hand-tuned static eval onto absolute (r,c,state) features + CAPACITY test

## Overview

Bead `nnue-trainer-d4a.6.1`. The decisive go/no-go for NNUE v3, and the producer of the
**warm-start weights** every downstream bead needs.

Fit a linear eval over the position-aware features the owner approved at the v3.0 gate:

```
eval_v3(board) = bias + Σ_{f active} weight_f
```

by ridge-regressing the **hand-tuned STATIC eval** onto the active-feature indicator vectors over
replayed real positions, then report the **capacity number: R² of `eval_v3` vs the hand-tuned
static eval on a held-out split**.

- **High R²** → position-aware single-cell features *can* reproduce hand-tuned → representation
  proven → proceed to the runtime leaf (`nnue-trainer-aov`) and the gauntlet (`d4a.6.2`).
- **Low R²** → single-cell granularity is too coarse → add pairwise/region features before any
  model work.

**This is a linear probe, not the final model.** It is deliberately the cheapest possible test of
whether these 1152 features can represent the eval at all. The fitted weights then serve as the
initialization for the real net in `nnue-trainer-1uz`.

**Why this is not a dead end** (owner goal 2026-07-26: "a bot that beats GoBot, with ML/retraining"):
the hand-tuned clone already beats GoBot 6-0 — it is the promotion bar in bead `nnue-trainer-0dj.8`.
So an eval that merely *matches* hand-tuned already beats GoBot. Distillation gets us to that bar
with a *learned* model; the retrain loop then pushes past it on outcome labels. Static-eval labels
cap at hand-tuned by construction, which is exactly why they are the warm start and not the
destination.

## Technical Details

**Feature definition** (unchanged from the approved gate): absolute `(row, col, cell-state)` on a
fixed 12x12 board, STM-perspective-normalized, `idx(r,c,state) = (r*12 + c)*8 + state`, 1152 slots.
Exactly 144 are active per position — one per cell.

**Labels**: the hand-tuned STATIC eval (depth 0), STM-relative, `movesLeft = 3`. Deliberately
static — this bead measures representational capacity, not strength.

**Ridge**: `w = (XᵀX + λI)⁻¹ Xᵀy`, bias unpenalized. `XᵀX` is 1152×1152 at worst — trivial to solve
directly; no iterative solver, no new dependency.

**Split**: by `game_id`. Never by position.

**Output** (`nnue_v3_weights.json`):

```
{
  "meta": {"lambda": L, "top_n": N, "split_seed": S, "games_train": G1, "games_holdout": G2,
           "positions_train": P1, "positions_holdout": P2, "r2_holdout": R, "bias": B},
  "weights": {"<feature_index>": W, ...}
}
```

  deep-search/outcome labels — the step that can actually exceed hand-tuned.
