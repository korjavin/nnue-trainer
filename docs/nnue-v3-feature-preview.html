NNUE v3.0 gate — absolute feature preview

Candidate v3 features mined from real games: every (row, col, cell-state) on the fixed 12×12 board, from the side-to-move's perspective, ranked by eval-discrimination — how far the hand-tuned evaluation of positions containing that feature sits from the corpus baseline. No model, no trained weights: this page exists so the shape of the feature set can be judged before any NNUE v3 is built.

How to read this. Features are ranked by eval-discrimination, not by frequency. Frequency ranking was the v2 bug: it promoted the most common shapes (a lone stone in a corner, near-empty windows), which are trivial. Common ≠ informative. Support (how many positions a feature occurs in) is used only as a floor — features below it keep their numbers but are unranked and drawn muted.

Each feature is an absolute board position, not a local window: cell (row, col) holding a given state. States are normalised to the side to move (self / opponent), so the same board read from either player yields mirrored features. A position is the board before a turn, its STM is that turn's player, and eval assumes a fresh turn ( moves left).

This is a pre-model preview. There are no learned weights here — only mined statistics over the hand-tuned evaluation. The gate is whether the top features look meaningful.

Board heatmaps by cell state

One 12×12 board per cell state. Each cell is shaded by that feature's signed deviation from the baseline, mean eval − baseline mean eval: green = positions with this feature evaluate better for the side to move, red = worse. Intensity is the magnitude (√-scaled). Muted cells are below the support floor; dashed cells were never observed. Hover a cell for its support, mean eval, discrimination and rank.
